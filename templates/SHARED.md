# Shared log

Where every agent writes. The project's real memory is linked at
`.samepage/memory/` and is READ-ONLY from here: it is a curated estate of
one-fact files with a strict index, and appending to it from another harness
corrupts that contract. So: read the estate, write here.

One line each, newest last, and only what is durable. A decision, a
constraint, a gotcha, a convention. Not routine work, git history has that.
A correction edits the line it corrects; never append a contradiction.

`- YYYY-MM-DD (agent) the fact`
